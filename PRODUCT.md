# Malarchy

<!-- impeccable:product-schema 1 -->

## Users and purpose

eD!'s personal Linux desktop and reproducible dotfiles, built on Omarchy. Keep its useful infrastructure while owning the visible identity and defaults.

## Platform and constraints

Linux desktop: Hyprland, Quickshell and terminal-based About/screensaver surfaces. Preserve Catppuccin and existing keyboard, shell, terminal and hardware configuration. Use supported user overrides; never change packaged Omarchy source. Installation must preserve existing files and remain repeatable.

## Brand commitments

Malarchy, pronounced “malarkey.” Tagline: “Listen here, jack. It’s your computer.” The user selected a weird 1990s magazine-clipping aesthetic, real Jason Sudeikis-as-Joe-Biden imagery, their personal Color Palettes note, and edequalsaweso.me as references. No AI-generated artwork.

## Scope

First pass: wallpaper, terminal branding, menu labels, reproducible installation and rollback instructions. No distribution replacement or application removal. Design and routine implementation choices are delegated by the current request. Photograph selection is for the user's local desktop; sourced photography and derived wallpaper remain local, outside the public repository.
